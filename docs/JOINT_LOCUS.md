# Reference coordinates / 参考坐标

XS uses a fixed single pair: F 1122–1138 and R 1282–1300 on AF049132.1, a 179-bp primer-inclusive reference span. It has no ordinary/A/B/D alternatives. / XS为固定单对，不设置普通、A、B、D平行方案。

S, M, L and XL each retain one shared coordinate tuple for ordinary, A, B and D. The 16 S–XL pairs cover four loci; adding XS gives 17 pairs across five loci. / S–XL各长度的普通、A、B、D起止坐标完全一致，加入XS后为五个位点、17对记录。

S–XL pass their terminal, thermodynamic and portfolio-specific background gates. XS is retained for experimental validation and explicitly exceeds the structure/background gates. A/B metrics refer to separate-PCR unions. / XS的结构与非目标筛查状态单独记录，A/B为独立PCR并集。
