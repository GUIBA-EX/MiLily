# 方法

参考坐标使用 AF049132.1 去除空位后的线粒体 16S rRNA，采用 1-based 坐标。S–XL 每个长度的普通与简并引物共享正反向起止坐标。

目标库包含 269 条记录，经分类与序列质量审核每个物种保留一条代表，共 128 个物种。S–XL 均为 19 个物种可评价，另外 109 个缺少必要结合区域。XS 保持原序列并单独评估。 非目标库包含 7177 条记录。主覆盖率和完全匹配率对可评价物种等权，各目的结果另列；缺失结合区域不计为漏检。

预测覆盖要求每条引物最多 2 个错配且末端 3 nt 与 IUPAC 碱基兼容；完全匹配要求两条引物均无错配。S–XL 目标双引物扫描要求产物总长 150–500 bp、引物间内部长度至少 50 bp；非目标扫描允许内部长度 0–1,000 bp。严格 WC/GT 保留末端约束；WC3/GT2 为不限制末端的宽松背景筛查，命中数为参考记录数。

D 引物每条最多 8 个具体变体，简并位点限于 3′ 半段。末端检查排除末端三连和超过 4 bp 的同聚物，要求末端 3 nt 含 GC。Primer3 使用 50 mM 单价盐、1.5 mM Mg²⁺、0.6 mM dNTP，并评估每变体 50 nM 与每方向总量 200 nM；结构 Tm 须低于 55°C，正反向双链 Tm 中点差不超过 5°C。XS 为手动设计，结构与非目标评估见 [XS 评估](../results/xs/assessment.json)。

C++ 与 Python 独立扫描使用同一参考数据，属于算法复核，不等于独立生物样本验证。实际表现仍需实验验证。
