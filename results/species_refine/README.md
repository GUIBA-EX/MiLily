# MiLily 简并引物：清理后参考比对的再筛选

按物种去重后，每个可评价物种等权；参考物种数较多的目对总体覆盖贡献更大。各目的结果单列，参考库物种数不能视为该目的全球物种数。

新候选使用既有结合坐标：普通、A、B 与 D 位置相同；每条引物的简并度 ≤8，简并位置只在 3′ 一半。保留原 D 引物作比较；海百合 XS 不参与重新设计。

本轮扩大候选池，分别筛选覆盖率优先方案，以及在同一背景门槛下、允许覆盖率最多降低 5 个百分点或一个物种（取较宽者）以提高完全匹配的方案。若结果相同只保留一次。门槛 20 或 100 是较宽松非目标扫描的最大记录数，同时严格非目标扫描最多 20 条。受搜索池、结构与背景条件限制，不代表全局最优。

预测覆盖要求正反引物分别最多 2 个错配且末端 3 碱基兼容；完全匹配要求两条引物均无错配。严格 WC/GT 为非目标序列记录数，分别表示标准配对模型和允许 G–T 的模型。两个值不可相加；实际扩增仍需实验验证。
